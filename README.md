# SLAY — Our dance world

Отдельный сайт команды SLAY. Репозиторий независим от `fizzarollio.github.io`; файлы основного сайта FIZZAROLLIO не менялись.

## Статус

Это интерактивный веб-прототип: навигация по разделам, демонстрационное расписание и библиотека танцев, локальные идеи/чат/профиль в браузере. Данные между участниками пока не синхронизируются. Для полноценной командной версии нужно подключить Supabase к интерфейсу, проверить политики доступа и настроить push.

## Публикация

Включите GitHub Pages для этого репозитория: Settings → Pages → Build and deployment → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` опубликует содержимое репозитория.
